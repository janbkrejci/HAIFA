# HAIFA — vývoj pokračuje jako GIRO

Aktuální zdrojový kód, nové úkoly a vydání najdeš v **[janbkrejci/GIRO](https://github.com/janbkrejci/GIRO)**. Tento repozitář zachovává historii, původní PR, issues a vydání HAIFA.

Ze starší instalace nejprve aktualizuj na [poslední HAIFA](https://github.com/janbkrejci/HAIFA/releases/latest). V dashboardu pak použij **„Klikněte zde pro přechod“**; nainstaluje GIRO a zachová data. Pro novou instalaci použij [vydání GIRO](https://github.com/janbkrejci/GIRO/releases/latest). Příkaz `factory` zůstává aliasem stejné instalace.

[Doložený průběh přechodu](https://github.com/janbkrejci/GIRO/blob/main/docs/rebranding/cutover.md) · [Příručka GIRO](https://github.com/janbkrejci/GIRO/blob/main/aifactory/src/aifactory/guide/02-instalace.md)


Další vydávání z tohoto repozitáře je vypnuté. Poslední HAIFA i všechna historická vydání zůstávají dostupná na původních adresách.
