# textstats

Python 3.11+, only the standard library. Code: `textstats.py`. Tests: `tests/`.

Test command (run it from the repository root):

    python -m unittest discover -s tests -t .

On macOS and Linux the interpreter may be `python3`. Every public function has a docstring,
is listed in `__all__` and has its tests in `tests/test_textstats.py`.
