# T27: Navigace, topbar a sdílené komponenty

Navigace, přepínač repozitářů, shell aplikace a topbar používají EN/CS katalogy. Přeložené jsou čipy aktualizace, knihovny, kontroly systému, systémových informací a limitů harnessů, bannery necommitnutých změn a restartu, společná potvrzení, načítání obrazovek, pickery kódů a modelů a záložky markdownového náhledu. Dokument mění titulek a `html lang` podle locale.

Popisky navigace a stavů se vyhodnocují při čtení, odvozené texty při renderu nebo v computed. `useConfirm.ask` přijímá i funkci vracející volby, takže překlad otevřeného potvrzení nezruší čekající odpověď. Tento režim používá ochrana neuložených změn a úklid disku. Výsledky úklidu a restartové chyby zůstávají přeložitelné i po dokončení požadavku. Vlastní názvy kroků kontroly se odvozují z uloženého kódu kroku a EN/CS katalogu, takže změna jazyka během kontroly aktualizuje tooltip i aria-label bez dalšího požadavku. Serverový diagnostický detail se připojuje beze změny. API detaily, cesty a uživatelský obsah se nepřekládají.

Regresní scénáře pokrývají otevřené menu s počty, tooltipy a aria-label, změnu titulku a lang, zachování instance obrazovky a rozepsaného vstupu, panel změn s plurály, otevřené potvrzení a jeho výsledek, timeout i selhání restartu, vyhledávání a výběr v pickerech a zachování markdownové záložky. Český kontext dotčených původních testů je explicitní.

Ověření provádí samostatný testovací krok workflow. Předchozí běh ověřil 1051 frontendových testů, lint a Python typecheck; frontend typecheck a browserová sada dosáhly limitu času. Nové regrese zahrnují přepnutí EN/CS/EN během běžící kontroly a překlad vlastních názvů kroků při zachování diagnostického detailu. Pro dokončení kontrol potřebuje frontend typecheck delší časový limit a multi-repo browserový scénář samostatný běh s rezervou. Tester má zahrnout všechny změněné testové soubory, katalogové testy a přímé konzumenty sdílených komponent. Distribuované assety a globální přepínač jsou součástí T35; obsah obrazovek a jejich specifické dialogy jsou rozdělené do T28–T34. T27 nepředstavuje dokončení celkové lokalizace dashboardu.
